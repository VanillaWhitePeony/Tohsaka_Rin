# 上游性能优化参考

来源：[astro-koharu 上游性能记录](https://github.com/cosZone/astro-koharu/blob/main/docs/performance/site-loading-2026-10-07.md)。

这份记录属于原主题的技术研究。原站评分、个人站链接和演示结果已从当前文档移除；本项目需要针对自己的配置和内容重新测量。

可继续参考的优化方向：

- 对比生产构建，并记录测试版本、设备、网络条件和多次测量的中位数。
- 优先加载首屏横幅，为不同屏幕提供适当尺寸的图片。
- 延迟加载非首屏交互组件，避免预取与首屏资源争抢带宽。
- 检查 CSS、字体和交互组件对布局偏移、渲染及主线程耗时的影响。
